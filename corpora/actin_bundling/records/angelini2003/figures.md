# Figure Digitization Log — `angelini2003`

Angelini, Liang, Wriggers & Wong, *Proc. Natl. Acad. Sci. USA* **100**(15), 8634–8637 (2003) (`corpus/actin_bundling/2003_Angelini.pdf`, PDF pages 1–4).

All figures in this PDF are embedded 150-ppi raster JPEGs (verified via `pdfimages -list` and pixel block quantization). Every quantitative panel was rendered at **1200 dpi** (exact `8×` upsampling of the native 150-ppi raster, where 1 native pixel = `8 px`), calibrated directly from detected axis ticks in each `figures/*.py` script, checked via `boxgraph figure check` into `figwork/`, and visually verified on overlay contact sheets (including 1:1 zoomed crops around all 15 extracted diffraction peak apices). Reported 95% intervals combine native pixel quantization (`±0.5` native px = `±4 px`), axis calibration residuals, curve thickness / peak-crest width, and local curve slope.
